# AI 청년 주거 이동 지원 서비스

청년 1인 가구가 이사 지역을 탐색할 때 필요한 주거 조건, 생활비, 지역 비교, 청년 주거지원 정보, 계약 준비를 한 흐름에서 확인할 수 있도록 기획한 React 기반 웹 프로젝트입니다.

> 현재 저장소는 **프론트엔드 초안 구현 단계**입니다. 화면에 표시되는 지역 점수·월세·정책·AI 답변의 상당수는 데모 데이터이며, 실제 계약·지원 신청 판단에 사용하면 안 됩니다.

## 기획 배경

청년 이사는 단순히 월세만 비교해서 결정하기 어렵습니다. 예산, 통근 시간, 생활 인프라, 안전, 청년 지원 정책, 계약 준비 서류를 여러 기관과 서비스에서 따로 확인해야 합니다.

이 프로젝트는 사용자가 조건을 입력하면 후보 지역을 비교하고, 생활비와 지원 정책을 확인한 뒤 계약 준비까지 이어갈 수 있는 주거 의사결정 흐름을 목표로 합니다.

## 핵심 사용자 흐름

```text
랜딩
  → 주거 조건 입력
  → AI 지역 추천 결과
  → 선택 지역 비교 / 지역 상세 탐색
  → 생활비·주거지원 정책 확인
  → 계약서·신청 서류 점검
```

## 현재 구현 기능

### 지역 추천 및 비교

- 4단계 주거 조건 입력
  - 월세 예산, 보증금, 방 형태, 희망 지역, 통근 시간, 생활 우선순위
  - 저장하고 나가기 및 초기화 확인 모달
  - 같은 브라우저 탭에서 마지막 진행 단계와 선택 지역 복원
- 추천 지역 TOP 3 목록
- 비교할 지역 선택 후 전용 지역 비교 화면 이동
- 지역 상세 탐색 화면
  - 주거비, 교통, 생활 인프라, 안전·재난, 주거지원 정책 점수
  - 조건 선택에 따라 지도 검색 결과와 마커 갱신

### Kakao 지도 연동

- Kakao Maps JavaScript SDK 기반 실제 지도 표시
- 지역 상세 화면의 조건별 장소 검색 및 마커 표시
- 헤더 지도 패널에서 장소·지역 검색
- 검색 결과 마커 클릭 시 장소명과 주소 정보 표시

### 생활비 분석

- 월 소득, 월세, 관리비, 식비, 교통비, 통신비, 기타 생활비 입력
- `비용 다시 계산` 버튼 클릭 시 월 총지출, 잔여 금액, 주거비 부담률 갱신
- 예시 지역별 월세 비교

### 지원·서류·커뮤니티

- 청년 월세 지원, LH·SH 청약, 지역 청년 이사 지원 카드
- 계약서/신청 서류 체크리스트 및 준비 상태 저장 목업
- 이용 가이드 FAQ
- 고객센터 FAQ, 문의 작성 목업
- 커뮤니티 Q&A
  - 분류, 검색, 정렬, 질문 등록, 답변 펼침, 도움돼요 상태 변경

### AI 추천 및 마이페이지

- 대화형 AI 지역 추천 UI와 빠른 질문 버튼
  - 현재 응답은 고정 데모 문구
- 마이페이지
  - 이사 조건, 관심 목록, 비교 기록, 계약서 분석 내역, 체크리스트, 알림 설정, 계정 정보 요약
  - 좌측 메뉴 클릭 시 마이페이지 내부 패널 전환

## 실행 방법

```bash
cd frontend
npm install
npm run dev
```

브라우저에서 Vite가 출력한 로컬 주소(기본 `http://localhost:5173`)로 접속합니다.

## 지도 환경 변수 설정

`frontend/.env.local` 파일을 만들고 Kakao JavaScript 키를 설정합니다.

```env
VITE_KAKAO_MAP_KEY=YOUR_KAKAO_JAVASCRIPT_KEY
```

Kakao Developers에서 다음도 설정해야 지도가 표시됩니다.

- 카카오맵 사용 설정: ON
- JavaScript 키의 JavaScript SDK 도메인 등록
  - `http://localhost:5173`
  - 필요 시 `http://127.0.0.1:5173`

`.env*` 파일은 Git 추적 대상에서 제외되어 있습니다. REST API 키와 Admin 키는 프론트엔드에 넣지 않습니다.

## 현재 한계

## 주거지원 정책 자료실

주거지원 정책 화면은 키워드·지역·제공기관·신청 상태 검색, 지원 유형 분류, 상세 자료, 공식 원문 링크, 브라우저 내 관심 자료 저장을 제공합니다. 전국 공통 정책은 지역 검색에 함께 포함됩니다. 분류는 정책명과 제공기관의 분류명을 바탕으로 정리한 탐색용 구분입니다.

### 공식 API 설정

`backend/.env.example`을 참고하여 서버의 `.env` 또는 환경변수에 다음 값을 설정하고 백엔드를 재시작합니다. 인증키를 프론트엔드나 `VITE_` 환경변수에 넣지 않습니다.

```env
YOUTH_POLICY_API_KEY=온통청년_청년정책_API_인증키
LH_POLICY_API_KEY=공공데이터포털_Decoding_인증키
```

- 온통청년: [인증키 신청](https://www.youthcenter.go.kr/myPage/openapi), [공식 API 문서](https://www.youthcenter.go.kr/cmnFooter/openapiIntro/oaiDoc). `getPlcy`의 주거 분야를 조회합니다.
- LH: [분양임대공고문 조회 서비스 활용신청](https://www.data.go.kr/data/15058530/openapi.do). 임대주택 유형 `06`을 조회합니다. **Decoding 키**를 사용합니다. 서버가 URL 인코딩합니다.

기존 Oracle DB 환경변수 설정이 필요한 Spring Boot 서버를 `backend/gradlew.bat bootRun`으로 실행합니다. 프론트엔드는 `frontend`에서 `npm run dev`로 실행합니다. Vite가 `/api` 요청을 `http://localhost:8080`으로 전달합니다. 운영 환경에서도 `/api`를 백엔드로 전달하는 프록시가 필요합니다.

추가 엔드포인트는 `GET /api/housing-policies/library`이며 `items`와 기관별 `sources`를 반환합니다. 기존 DB 정책 조회 API는 유지합니다. 응답은 15분간 메모리 캐시하고 오류 시에는 1분 후 재시도합니다. 각 기관에서 최대 1,000건을 수집하며, 수집 한도나 일부 실패는 응답의 `truncated`와 상태에 표시합니다. LH 조회 기간은 현재 기준 전후 1년입니다. 목록에 나온 공고 게시일은 신청 시작일로 사용하지 않습니다. 온통청년의 명시된 신청 날짜를 확인할 수 없으면 `공고 확인`으로 표시합니다.

인증키 미설정, 기관 장애, 일부 수신을 구분합니다. 화면 예시는 사용자가 **자료실 화면 예시 보기**를 눌렀을 때만 표시하고 실제 API 자료와 합치지 않습니다. 현재 인증키가 없어 공식 API 실수신 검증은 수행하지 않았습니다. 키 발급 후 제공기관의 실제 응답으로 확인이 필요합니다.

```powershell
# frontend
npm run test:policies
npm run build
# backend
.\gradlew.bat test
```
